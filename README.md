# Secret Number Game

A simple web-based game where the user tries to guess a randomly generated number between 1 and 10.

## Description

This project is a fun and interactive number-guessing game built with HTML, CSS, and JavaScript. The application generates a secret number, and the user has to guess it. The game provides feedback on whether the guess is too high or too low and counts the number of attempts until the correct number is guessed.

## Features

- **Random Number Generation**: A new secret number is generated at the start of each game.
- **User Input**: An input field for the user to enter their guess.
- **Interactive Feedback**: The game informs the user if their guess is higher or lower than the secret number.
- **Attempt Counter**: Tracks how many attempts the user has made.
- **Restart Game**: A "New Game" button to reset the game and generate a new secret number.

## Setup and Installation

No special setup is required to run this project. You only need a web browser.

1.  **Clone the repository or download the files:**
    ```bash
    git clone <repository-url>
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd <project-directory>
    ```

## Usage

1.  Open the `index.html` file in your preferred web browser.
2.  The game will start automatically.
3.  Enter a number between 1 and 10 in the input field.
4.  Click the **"Intentar"** (Try) button to submit your guess.
5.  Follow the on-screen feedback to adjust your next guess.
6.  Once you guess the correct number, you can click the **"Nuevo juego"** (New game) button to play again.

## File Structure

-   `index.html`: The main HTML file that structures the web page.
-   `style.css`: The stylesheet that defines the visual appearance of the game.
-   `app.js`: The JavaScript file that contains the game's logic and interactivity.
-   `img/`: A directory containing images used in the application.
